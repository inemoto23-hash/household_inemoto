## 1. 配色とスタイルの刷新

### 診断

| 症状 | 原因 |
|---|---|
| 安っぽく見える | カード・入力欄・タイル・選択状態すべてに 1px の枠線。線が多い画面は情報が整理されて見えない |
| 選択状態が浮く | 色の選択中に `3px solid var(--text)`（ほぼ黒）の輪。周囲の淡い配色と合わない |
| 家計簿らしくない | 主色が紫がかったインディゴ（`#4f46e5`）。業務アプリの色で、安心感の方向とは違う |
| カテゴリ色が騒がしい | 10色すべて原色に近く、並ぶと喧嘩する |

### 方針

**枠線で区切らない。面の濃淡と柔らかい影で区切る。**
線は「どうしても必要な区切り」だけに残し、色はほぼ透明（`rgb(23 43 63 / 6〜7%)`）にした。

主色は**通帳の藍**（`#2c5578`）。影も地の色味に合わせて青を含ませている。

| 対象 | 変更 |
|---|---|
| カード | 枠線を削除。影 + 上辺のハイライトのみ |
| 入力欄 | 枠線を削除。少し沈んだ面（`inset` 影）で「書き込む場所」を示す |
| ボタン | ghost / danger の輪郭を廃止し、面で示す |
| 選択状態 | 黒枠 → **淡いアクセント面 + 内側 1.5px の細い輪**（`.pick`） |
| 色見本 | 白い内側の輪で抜く。黒枠を色に重ねない |
| カテゴリ色 | 彩度を落とした12色へ |
| タイル | 枠線を削除。色は淡い面と文字色で表す |
| 角丸 | 18 → 20px、タイル 13px |
| カレンダー | セルの枠線を廃止し、面の濃淡で区切る |

追加/変更したトークンはすべて**3状態**（明示 light / 明示 dark / OS 追従）で定義済み。

## 2. 既定予算（設定＝デフォ値、予算ページ＝その月）

### `007_default_budget.sql`

`budget_categories.default_amount BIGINT NOT NULL DEFAULT 0` を追加。

### 動き

1. **設定 → 予算タブ**でカテゴリごとに「毎月の予算」を入れる
2. 新しい月を初めて開いた時点で、その額が配分として入る（`reason = 'initial'`、備考「既定の予算から」）
3. その月だけ変えたいときは**予算ページで上書き**する

`ensurePeriod()` が `budget_periods` の行を作った回だけ配分を投入する。
期間の有無で判定するため、あとから既定額を変えても**過去の月には遡らない**。
`budgetsGet` からも呼ぶので、月を開くだけで初期化される。

役割分担が明確になった。**月ごとに変動するものは予算ページ、既定値は設定ページ。**

## 3. 不具合修正

### 口座の並べ替えが元に戻る

`GET /api/accounts` が `ORDER BY is_priority DESC, order_index, name` で返していた。
優先表示の財布を先頭へ出す並びは**選択欄のためのもの**で、並び順の編集画面には合わない。
保存した order_index どおりに並べても、再取得で優先財布が上へ跳ね返っていた。

`?sort=order` を追加し、管理画面はそちらを使う。選択欄側の並びは変えていない。

### ナビの折り返し

4項目になり「カレンダー」が2行に割れていた。
`white-space: nowrap` と字送りの調整、狭い画面での文字サイズ13px化で1行に収めた。

### アイコンが選択後も小さい

`IconPicker` の上部に **60px の大きなタイル**で選択中のアイコンを出す。
色を選んでいればその色を反映し、外すボタンも置いた。
