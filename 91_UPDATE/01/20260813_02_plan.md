# プラン: 20260813_02 — 月の切り替えをヘッダーへ一本化する

## 対象機能・課題

### いまの形

月の切り替えが**3画面それぞれに書かれている**。

| 画面 | 実装 |
|---|---|
| カレンダー | `CalendarPage.tsx:190,202`（`?d=` を保つ） |
| 予算 | `BudgetPage.tsx:320,331` |
| 分析 | `AnalyticsPage.tsx:463,474` |

同じものが3つあり、**画面の上部を毎回1行ぶん占有**している。
カレンダーでは、その1行がカレンダー本体を下へ押し出していた。

### 幅の問題

前回、月と 支出/収入/収支 を1行に収めたが、**390px 未満では2行になる**。
月＋前後移動＋3つの金額を読める大きさで並べるには 390px 以上が要る（実測）。

| 幅 | 6桁 | 7桁 |
|---|---|---|
| 320 / 360px | 2行 | 2行 |
| 390px | 1行 | 2行 |
| 412px 以上 | 1行 | 1行 |

**月をヘッダーへ出せば、この問題は消える。** 残るのは金額3つだけになり、320px でも収まる。

### ヘッダーは既に固定されている

`.app-header` は `position: sticky; top: 0`（`tokens.css:531-539`）。
**スクロールしても残る**ので、月の切り替えを置く場所として理にかなっている。

---

## 設計の要点

### 月を持つ画面だけに出す

ヘッダーは全画面共通なので、月を持たない画面（口座・設定・確定・一括・状態）では**何も出さない**。

| URL | ヘッダーの月 |
|---|---|
| `/calendar/:ym` `/budget/:ym` `/analytics/:ym` | 出す |
| それ以外 | 出さない |

**現在地から月を書き換える。** ヘッダーは自分がどの画面にいるかを見て、
同じ画面の別の月へ移る。カレンダーだけは `?d=`（選択日）を保つ——
月を移動して選択日が消えると、戻ったときにどこを見ていたか分からなくなる。

### 3画面から月の切り替えを消す

同じものが3つある状態を残さない。編集シート・一覧シートを共有したのと同じ判断で、
**実装をひとつにする**。

見出しは残す（`◯月の予算` → `予算`）。月はヘッダーに出ているので重複させない。

### 置き場所

ヘッダーは2段（`.app-header-inner` が `flex-direction: column`）。
1段目にブランド、2段目にナビがある。**月は1段目の右端**に置く。

```
┌──────────────────────────────┐
│ 🌊 KakeiFlow      ‹ 2026年8月 › │  ← sticky
│ [カレンダー][予算][口座][分析][設定] │
└──────────────────────────────┘
```

狭い画面ではブランドのワードマークを隠し、マークだけにして場所を空ける。
**月のほうが操作であり、ブランドは飾り**なので、削るならブランド側から。

### 押しやすさ

前後の矢印は指で押せる大きさ（最低 40×40）を確保する。
ヘッダーは常に見えているぶん、誤爆すると影響が大きい。

   何も出ないこと、レイアウトが崩れないことを必ず確認する

   ここは既存の振る舞いなので必ず引き継ぐ
