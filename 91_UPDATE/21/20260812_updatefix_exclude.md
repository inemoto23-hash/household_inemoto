## 1. PC で使えなかった件（解消）

「PCから開くと残高等が出ず使えないページになっている」との報告。
**位置情報は無関係だった。**

### 切り分け

CDP（Chrome DevTools Protocol）で Chrome を起動し、実際に開いて確かめた。

| 確認したこと | 結果 |
|---|---|
| 画面の描画 | 正常。例外なし（`root` に要素あり、サインイン画面が出る） |
| 通信の失敗 | `favicon.ico` の 404 のみ（無害） |
| CORS | SWA のオリジンに対して preflight・本体とも許可が返る |
| BE の口座問い合わせ | SQL を直接流して正常 |

**画面の枠は出るがデータだけ出ない**という症状の形から、
トークンの取得経路に絞り込んだ。

### 原因

`lib/api.ts` の `getAccessToken` が、無音更新の失敗を
**`InteractionRequiredAuthError` だけ**で見ていた。

MSAL は隠しフレームで `login.microsoftonline.com` を開いてトークンを更新する。
サードパーティ Cookie が制限された環境や、フレームが時間内に応答しない環境では
`BrowserAuthError`（`monitor_window_timeout` など）で落ちる。
この型は上の条件に当てはまらないため、**サインインし直しへ倒れず例外だけが投げられ**、
すべての API 呼び出しが失敗していた。画面の枠は出るのでデータだけが欠ける。

### 直したこと

理由を問わず、まずはサインインし直しへ倒す。
飛ばした先でも失敗したら往復させず、理由を見せて止める（`sessionStorage` の歯止め）。
成功したら歯止めを消す。

口座ページは、0円の合計より**先に**取得エラーを出すようにした。
「残高が出ない」だけでは何が起きたか分からないため。

**利用者から復旧を確認済み。**

## 2. 予算の母数を画面に出した

「予算タブの配分が未だに母数を変える」との指摘。

コード上は「残りを設定」に変わっており各行の分母も母数だったが、

`budgetsGet` の `total` に `baseline` と `adjusted` を足し、上部は
**「予算（母数）」＋調整** を出すようにした。残りを直しても母数は動かない。

## 3. 母数の置き場所は変えていない（文言を直した）

「設定画面の予算tabから予算母数の組み換えが無くなっている」との指摘だったが、
**設定 → 予算タブの「毎月の予算」がその母数**であり、機能は消えていなかった。
文言が実際の動きと合っておらず、母数だと読み取れなかったのが原因。

| 箇所 | 変更 |
|---|---|
| 見出し | 「毎月の予算（既定額）」→ **「毎月の予算（母数）」** |
| 説明 | 「新しい月を開いたときに入ります」→ **「月を締めたときに翌月の母数になります」** |
| 一覧 | 「毎月 ¥133,300」→ **「母数 ¥133,300」** |
| 節の説明 | 「ここで決めた『毎月の予算』が大元の母数です」を追加 |

**説明文が実際の動きから遅れていた。** 月次確定の変更に合わせて直すべきだった。

## 5. 合計に含めない印

`20_DATABASE/migrations/016_exclude_from_totals.sql`。
`accounts` と `budget_categories` に `exclude_from_totals` を追加。

### 判断したこと

**アーカイブとは別物にした。**

| | 意味 | 一覧 | 記録で選べるか | 合計 |
|---|---|---|---|---|
| アーカイブ | もう使わない | 消える | 選べない | 入らない |
| 合計に含めない | 使うけれど数えない | 出る | 選べる | 入らない |

混ぜると「使いたいのに隠れる」か「数えたくないのに数えられる」になる。

**外すのは合計だけ。** 分析タブの内訳には出す。何に使ったかは見たいため。

**合計を出している場所を洗い出して潰した。** どこか1つ数え漏らすと
画面ごとに違う数字が出る。対象は口座ページの財布・クレジット合計と、
`budgetsGet` の `total` の2か所。

### 画面

口座とカテゴリの編集シートに「合計に含めない」のチェック。
一覧の行にも `∑ 合計外` と出るので、**開かずにどれが外れているか分かる**。
口座ページには「合計に含めない口座が N 件あります」と添える。
数字が合わないときに理由が画面から分かる状態にする。
