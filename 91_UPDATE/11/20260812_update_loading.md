## 先に潰す危険：スプラッシュに閉じ込める

BE が落ちている・トークンが取れないときに**ロゴが永久に回り続ける**と、
真っ白な画面より悪い。原因が一切読めなくなる。

止め方を三重にする。

| どこで | いつ消すか |
|---|---|
| 未認証 | サインイン画面の描画時に即 |
| 認証済み | `['bootstrap']` が**解決または失敗**したとき |
| `main.tsx` | **8秒の安全弁**。上のどちらも来なくても必ず消す |

`main.tsx` の「初期化に失敗しても必ず描画する」と同じ考え方。
**サインインできないことと、画面が出ないことは別の話にする。**

## 注意する点

- **スプラッシュは `index.html` に素で置く。** React コンポーネントにすると
  JS バンドルの取得・評価が終わるまで出ず、**いちばん白い時間に間に合わない**
- **インライン CSS からトークンは引けない。** ブランド色はリテラルで書くことになるため、
  `tokens.css` の `--brand-a` / `--brand-b` と**ずれる**。index.html 側にその旨を明記する
- **最低表示 450ms を守る。** キャッシュが効いているときに一瞬だけ光って消えると、
  それ自体が不具合に見える
- **`['bootstrap']` は既存と同じ queryKey を使う。** アプリシェルに張っても
  リクエストは増えない（キャッシュ共有）
- **スケルトンの寸法は呼び出し側に書かせない。** `Money` と同じ `size` を渡す作りにする。
  ずれると値が入った瞬間にレイアウトが跳ねる
- **止まっても崩れない絵にする。** `prefers-reduced-motion` は `tokens.css` の
  全体ルールで波が静止する。静止状態が現在のロゴと同じ見た目になること
